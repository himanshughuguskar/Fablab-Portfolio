The Surface — Data Communication

The first breath before the dive. Understanding what data communication really means, the pieces that make it work, and how data actually travels from one device to another.

Meaning and basics of data communication Components of data communication Data transmission Characteristics of data communication
Completed
  • Data communication is the exchange of data between two devices through some form of transmission medium.
  • Five components: message, sender, receiver, transmission medium and protocol.
  • Data transmission modes: simplex (one way), half duplex (one direction at a time) and full duplex (both ways together).
  • Four characteristics: delivery to the correct destination, accuracy, timeliness and low jitter.

Day 02
30m Deep

Shallow Waters — Computer Networks

Many devices, one shared ocean. Why we connect machines together at all, and how networks are classified by the area they cover.

What is a computer network? Need for networking Types of networks PAN, LAN, MAN, WAN
Completed
  • A computer network is a set of devices connected by links so they can share data and resources.
  • Need for networking: resource sharing, communication, centralised data, cost saving and reliability.
  • PAN — a few metres, around one person (Bluetooth, hotspot).
  • LAN — a room, lab or building. MAN — a city. WAN — countries and continents, like the Internet.

Day 03
45m Deep

Coral Reef — Topologies & Networking Devices

The shape of the reef decides how life flows through it. Learning how devices are arranged physically and the hardware that keeps the traffic moving.

Network topologies Bus, Star, Ring, Mesh, Hybrid Hub and Switch Router
Completed
  • Bus — one backbone cable, cheap but a single break affects everyone.
  • Star — every node joins a central hub/switch; easy to manage, central device is critical.
  • Ring — data travels in a loop, token passing style. Mesh — every node linked to every other, very reliable but costly.
  • Hybrid — a mix of two or more topologies, used in real campuses.
  • Hub broadcasts to all ports, Switch forwards by MAC address, Router connects different networks and forwards by IP address.
Bus Star Ring Mesh Hybrid

Day 04

Diving in Depth — OSI Model & Protocols

Seven layers of water between you and the seabed. Understanding how the OSI model splits communication into layers, and why protocols are the rules of the ocean.

Introduction to OSI model Seven layers of OSI Functions of each layer Introduction to network protocols Importance of protocols
Completed
  1. Physical — bits, cables, signals, connectors.
  2. Data Link — frames, MAC addressing, error detection.
  3. Network — logical addressing (IP) and routing.
  4. Transport — end to end delivery, TCP and UDP, segmentation.
  5. Session — starts, manages and ends sessions.
  6. Presentation — translation, encryption, compression.
  7. Application — services the user touches: HTTP, FTP, SMTP.

Why protocols matter: they give both sides the same rules for format, timing, addressing, error handling and sequencing — without them the data is just noise.

Day 05

Ocean Currents — HTTP, IP, DHCP & DNS

The currents that carry the whole web. How browsers talk to servers, how devices are addressed, how addresses are handed out and how names become numbers.

Introduction to HTTP HTTP methods: GET, POST, PUT, DELETE IP addresses IPv4 and IPv6 DHCP DNS
Completed
  • HTTP is a stateless request–response protocol of the application layer used by the web.
  • GET reads data, POST creates data, PUT updates data, DELETE removes data.
  • IPv4 — 32 bit, dotted decimal like 192.168.1.1. IPv6 — 128 bit, hexadecimal like 2001:db8::1, far more addresses.
  • DHCP automatically assigns IP address, subnet mask, gateway and DNS to a device.
  • DNS resolves a human readable domain name into an IP address.
GET POST PUT DELETE

Deep Currents — ARP, ICMP & Revision

Bringing light to the deep. The helper protocols that map addresses and report problems, followed by a full revision of everything learnt so far.

What is ARP What is ICMP Revision of previous topics
Completed
  • ARP (Address Resolution Protocol) finds the MAC address that belongs to a known IP address inside a local network.
  • ICMP (Internet Control Message Protocol) carries error and diagnostic messages — this is what ping and traceroute use.
  • Revision: data communication basics, network types, topologies and devices, OSI layers, and the HTTP / IP / DHCP / DNS family.

Jellyfish — WebSocket & Project Discussion

The glowing deep. Real-time, always-open connections between client and server, peer to peer media with WebRTC, and turning all of it into project ideas.

What is WebSocket What is Web Real-time Communication (WebRTC) Project ideas and discussion
Completed
  • WebSocket gives a single, long lived, full duplex connection over TCP — the server can push data without the client asking again.
  • WebRTC allows browsers to exchange audio, video and data directly peer to peer, with very low latency.
  • Project ideas: real-time chat app, live network dashboard, IP / subnet calculator, ping & traceroute visualiser, video call demo.
